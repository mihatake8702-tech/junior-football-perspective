# 8人制 ポジションドリル

8人制サッカーの戦術を、ポジション別・レベル別（Lv1〜10、全120問）に学べるWebアプリです。

- 選手用：<https://mihatake8702-tech.github.io/soccer-drill/>
- コーチ用（チームの成績を受け取る準備）：<https://mihatake8702-tech.github.io/soccer-drill/coach.html>
- 作戦ボード（コーチ用）：<https://mihatake8702-tech.github.io/soccer-drill/board/>

選手の名前と成績は、選手の端末と、各チームのコーチのGoogleスプレッドシートにだけ保存されます。

作戦ボードの選手名・保存した配置・練習メニューは、その端末のブラウザの中にだけ保存されます。
